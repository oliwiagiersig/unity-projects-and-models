## Game Projects

### Dragon Hatchery

An individual 3D game project created in Unity.  
The scene presents two dragon eggs that can be selected and hatched through user interaction.

**My work included:**
- creating original egg models in Blender,
- preparing animations and interactive objects,
- designing the user interface,
- implementing sounds and click-based interactions,
- modifying and testing simple C# scripts.

[View Dragon Hatchery](https://github.com/oliwiagiersig/unity-projects-and-models/releases/download/dragon-hatchery-v1.0.0/DragonHatchery_Build_4.zip)

### Matcha Game

A team-based 3D arcade game consisting of three levels.

**My work included:**
- supporting the development of gameplay mechanics,
- working on the timer, points system and end-game panel,
- testing level transitions and gameplay reset,
- working with interactive objects and sound.
